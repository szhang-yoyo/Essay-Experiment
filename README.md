# Phase 3–5 MPI Development

This branch preserves the distributed-memory development and experimental work from Phases 3–5, before the final ten-repeat rerun and dissertation sensitivity experiments.

It contains the MPI CG/PCG implementation, Block Jacobi and Additive Schwarz development, Phase 3 strong/weak scaling data, Phase 4 profiling, and Phase 5 timing, validation, and rerun data.

The final ten-repeat scaling rerun and final sensitivity experiments are maintained separately on the `final-dissertation` branch.
