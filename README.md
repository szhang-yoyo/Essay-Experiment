# MSc HPC Dissertation – Serial Development

This branch contains the early serial development of the dissertation project.

## Contents

- Phase 1: serial 1D Poisson experiments
- Phase 2: serial 2D Poisson experiments
- Initial numerical validation and solver development

These stages provide the foundation for the later distributed-memory implementation.

## Branch Structure

- `main` – serial development, Phases 1–2
- `phase3-mpi` – MPI implementation and Phases 3–5
- `final-dissertation` – Final10 rerun, validation, and sensitivity experiments
